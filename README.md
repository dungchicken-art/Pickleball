# Pickleball Booking (Demo)

Trang web tĩnh gồm giao diện người chơi và quản trị, đồng bộ qua `localStorage`. UI được làm mới với Bootstrap 5 và font Inter để tăng độ hiện đại.

## Chạy nhanh
Mở trực tiếp file `index.html` hoặc dùng máy chủ tĩnh tùy ý (vd: `npx serve .`).

## Tài khoản mẫu
- Người chơi: `user@pickle.com` / `play123`
- Admin: `admin@pickle.com` / `verify123`

## Quy trình
1. Người chơi đăng nhập, nhập lịch, thông tin chuyển khoản và gửi đi.
2. Dữ liệu lưu tại `localStorage` và xuất hiện ở bảng điều khiển admin.
3. Admin đăng nhập, xem từng giao dịch và bấm **Xác nhận** hoặc **Từ chối / cần bổ sung**.
